### TypeScript Fixes

Three type errors caught and fixed before tsc:

1. **`SegmentedControl` API mismatch in `I18nSettingsScreen.tsx`** — The file (created last session) had used `options: string[]` + `selectedIndex: number` + `onChange: (i: number) => void`. The actual primitive uses a generic `SegmentedOption<T>` interface with `value: T` and `onChange: (value: T) => void`. Fixed by converting to typed option objects and using the `value`/`onChange` pattern.

2. **`ShareTargetRow` wrong usage in `FirstRunExtrasScreen.tsx`** — The file had passed `icon` and `label` props which don't exist on `ShareTargetRow` (a contact card primitive taking `name` + `initials`). Fixed by removing the import entirely and rendering a `Pressable` with inline icon/label layout instead, which is semantically correct for app-share targets.

3. **`colors.primarySubtle` non-existent token in `LegalExtrasScreen.tsx`** — The token set doesn't have `primarySubtle`. Replaced with `colors.primary10` (`rgba(227, 169, 160, 0.1)`).

After fixes: `npx tsc --noEmit` → 0 errors.

## Lessons

- Always verify actual prop signatures against the real primitive file before using them in parent screens — the auto-generated screen files from prior sessions had two wrong prop assumptions (SegmentedControl, ShareTargetRow).
- `colors` token set doesn't include `primarySubtle` — the available opacity variants are `primary10` and `primary20`.
- When writing tests that check text content, prefer `getByTestId` for title/reason fields to avoid false positives when the same substring appears in multiple elements (e.g., "link" appearing in both the heading and the body text).
