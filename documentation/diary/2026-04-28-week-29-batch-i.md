## Decisions Made
1. Decision: `LegalPageLayout` jump links derived from `sections` array, not a separate `jumpLinks` prop.
   - Why: Jump links are always derived from section headings; having a separate prop would require callers to keep them in sync.
   - Impact: One tsc error found in tests where `jumpLinks` was passed directly → fixed by passing `sections` instead.

2. Decision: `AuthEdgeScreen` uses a single discriminated-union `view` prop covering 9 edge cases.
   - Why: All auth edges share enough infrastructure (ModalSheet, MfaOtpInput, DeviceRow, RecoveryCodesList) that splitting into 9 files would create significant duplication and navigation complexity.
   - Impact: One test suite covers all 9 views cleanly.

3. Decision: `DeletionConfirmationModal` does not include `autoCapitalize` on the phrase field.
   - Why: `autoCapitalize` is not a valid prop on `InputField` (discovered during tsc check). Uppercase enforcement would need a custom `onChangeText` transform.
   - Impact: W29-DEBT-3 registered for future polish. Deletion flow still requires typing "DELETE" exactly.

4. Decision: `RecoveryCodesList` uses plain solid borders instead of `borderBottomStyle: "dotted"`.
   - Why: `borderBottomStyle` is a web-only CSS property — invalid in React Native `StyleSheet.create`.
   - Impact: Visually slightly different from design intent; functionally correct. Noted in close report.

5. Decision: `ChangeCredentialsScreen` binds `onChangeConfirmValue ?? (() => {})` to `InputField.onChangeText`.
   - Why: `onChangeConfirmValue` is an optional `(v: string) => void` but `InputField.onChangeText` requires a non-optional function.
   - Impact: Safe no-op fallback; fixes tsc error without changing external API.
