## Decisions Made
1. Decision: Split staff domain types into `src/shared/staffTypes.ts` (primitives safe for shared/ui) + `src/app/staff/staffHelpers.ts` (app-level types and utilities).
   - Why: `QueueCard` and `AISuggestionCard` are shared-UI primitives that need access to `StaffQueueStatus` and `AISuggestion` types — these can't import from `src/app/staff/`.
   - Impact: Clean import boundary; shared/ui components depend on shared/staffTypes, not on app-layer modules.

2. Decision: `AIChatScreen` combines 3 views (chat / suggestions / budget-info) in a single file via `view` prop.
   - Why: All three views share the same AI budget context and the same `AISuggestionCard` component. A single discriminated-union prop is simpler than 3 separate screen registrations.
   - Impact: Single test suite covers all 3 views.
