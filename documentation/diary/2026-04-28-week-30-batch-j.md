### TypeScript Errors Fixed (8 fixes)

Running `npx tsc --noEmit` after session recovery revealed 8 classes of type errors across the W30 files:

1. **`radius.pill` doesn't exist** — The token shape only has `none`, `sm`, `md`, `lg`, `xl`, `xxl`, `full`. Six files were using `radius.pill`; all replaced with `radius.full` (also 9999).

2. **`StickyFooterCta` prop mismatch** — The primitive uses `primaryLabel`/`onPrimaryPress`/`primaryDisabled`/`primaryLoading`. Two call sites in `MultiServiceBookingScreen.tsx` were using the old pattern `label`/`onPress`/`disabled`/`loading`.

3. **`InputField` unsupported props** — `InputField` controls keyboard type internally via its `variant` prop (`text`, `email`, `phone`, `password`, `otpCell`) and doesn't accept bare `keyboardType`, `editable`, or `multiline`. Three files were passing those. Fixed: used `variant="otpCell"` and `variant="phone"` where needed, `disabled` instead of `editable`, and removed `multiline` (InputField is always single-line).

4. **`BookingService` not exported from `ServiceSelectionScreen`** — That type is defined in `bookingHelpers.ts` and imported (not re-exported) by `ServiceSelectionScreen`. Split the import in `MultiServiceBookingScreen.tsx`.

5. **`PaymentMethodRowProps` has no `id` field** — `SplitPaymentSheet` uses `methods.map((m) => ... key={m.id})`. Typed the `methods` array as `(PaymentMethodRowProps & { id: string })[]` to accommodate the key usage.

6. **`CurrencyInput` requires `onChangeText`** — It's a required prop (string state updater). `WalletTopUpSheet` was passing only `onChangeValue` (the numeric callback). Fixed to use `onChangeText={s => { setCustomValue(s); setSelectedPreset(null); }}`.

7. **`RatingStars` wrong prop names** — In `ReviewsEdgeScreen`, was calling `<RatingStars rating={...} size="sm" />`. Correct API: `value` (not `rating`) and `size` is `16 | 20 | 32` (not a string alias). Fixed to `value={review.rating} size={16}`.

8. **`LegalPageLayout` doesn't accept a `sections` prop** — It uses `children: ReactNode`. `ReviewGuidelinesPage` was passing `sections={GUIDELINES_SECTIONS}` directly. Refactored to map the sections array to JSX children (`<View>` + `<Text>` pairs) and added corresponding `guidelineSection`/`guidelineHeading`/`guidelineBody` styles.

After all fixes: **`npx tsc --noEmit` → 0 errors**.

## Technical Decisions Made

- **`radius.full` not `radius.pill`** — Confirmed the token shape; going forward always check `tokens.ts` before using radius tokens.
- **`InputField.variant` controls keyboard type** — The variant enum (`text`/`email`/`phone`/`password`/`otpCell`) maps to the correct `keyboardType` + `autoComplete` internally. Never pass `keyboardType` directly.
- **Recurring bookings = post-launch** — `RecurringBookingSheet` is delivered but flagged; navigator will show "Coming soon" before enabling.
- **`LegalPageLayout` children pattern** — Any content that isn't already a standard field list must be rendered as JSX children, not passed as a `sections` array.
- **`CurrencyInput` dual callback** — `onChangeText` for raw string state; `onChangeValue` (optional) for numeric side-effects. Both can be used simultaneously.
