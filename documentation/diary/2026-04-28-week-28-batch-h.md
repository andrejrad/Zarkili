## Decisions Made
1. Decision: `SaveToggle` and `SavedToast` exported from a single `SaveToggle.tsx` file.
   - Why: These two components are always used together; co-locating them reduces import overhead and keeps the save-state interaction logic in one place.
   - Impact: Both exported via `src/shared/ui/index.ts` as separate named exports.

2. Decision: `PostCard` uses `rgba(0,0,0,0.40)` View instead of `LinearGradient` for image scrim.
   - Why: Adding `expo-linear-gradient` to the dependency tree was out of scope for a code-only week. A View-based scrim is functionally identical for the current design.
   - Impact: W28-DEBT-1 registered to upgrade to `LinearGradient` in a future polish pass.

3. Decision: `ShareSheetScreen` is a bottom-sheet content component; parent renders inside `ModalSheet`.
   - Why: Consistent with how other sheet-content screens (e.g., WaitlistJoinSheet) are structured. Parent controls the sheet lifecycle.
   - Impact: `ShareSheetScreen` has no `ModalSheet` dependency; simpler to test in isolation.
